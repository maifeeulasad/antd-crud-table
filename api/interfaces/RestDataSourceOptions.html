    OptionalconfigureRequest

    configureRequest?: (
        context: RestRequestContext<T, K>,
    ) => RestRequestOverrides | Promise<RestRequestOverrides>

    Adjusts a request as it is made.

    Runs per call and may be async, so it covers what static options cannot: a rotating or awaited token, a header only one operation sends, a verb chosen from the payload. Its result is merged over the static options.
