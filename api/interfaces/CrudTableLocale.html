    Interface CrudTableLocale

    Every user-visible string the library produces.

    Interpolated strings are functions rather than templates with placeholders, so a translation cannot silently drop a value or get the argument order wrong - the compiler checks it.

    antd's own chrome (pagination, empty states, date pickers) is localised through antd's ConfigProvider, and ProTable's chrome through its intl. CrudTable derives both from the surrounding ConfigProvider when there is one, so a consumer usually sets their app locale once and this object only needs supplying to override the library's own wording.
